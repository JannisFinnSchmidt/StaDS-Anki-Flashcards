# Statistics & Data Science Flashcards

This repository contains around 1900 **Anki** Flashcards covering selected topics of Statistics and Data Science. 
These cards are *not* intended as exam preparation tools - most exams at LMU allow a so called *cheat sheet* anyways - 
but rather as a long‑term learning resource to help maintain and reinforce key concepts after completing the respective courses.

## Topics
The covered topics include:
- Bachelor's Level:
  - Numerical Analysis
  - Ordinary Differential Equations
  - Statistics 1 & 2
  - Selected Topics of Statistics 
- Master's Level:
  - Deep Learning 
  - Deep Learning for NLP 
  - Optimization 
  - Regression for Correlated Data 
  - Statistical Inference 
  - Statistical Modelling 
  - Supervised Learning 
  - Survival Analysis 

## How to install
1. Get the *Anki* application on your device
2. Download the Flashcards as .txt files from this repository
3. Open Anki → **File → Import…**
4. Select one of the .txt files
5. Import specifications can be left unchanged
6. Repeat for all .txt files that you are interested in
